Linux Command Practice

Command| Purpose
"pwd"| Displays the current working directory
"ls"| Lists files and folders
"mkdir"| Creates a new directory
"touch"| Creates an empty file
"cat"| Displays file contents
"whoami"| Displays the current username
"id"| Shows user and group information
"ls -l"| Displays file permissions

Linux Permissions

Linux permissions control access to files and directories.

- Read (r) – View content
- Write (w) – Modify content
- Execute (x) – Run a file or access a directory

Permissions apply to the owner, group, and others.

DNS Record Types

- A – Maps a domain to an IPv4 address
- AAAA – Maps a domain to an IPv6 address
- MX – Specifies mail servers
- TXT – Stores text information associated with a domain

Reconnaissance

Reconnaissance is the information-gathering stage of a security assessment.

Passive Reconnaissance

Collecting information from publicly available sources without directly interacting with the target system.

Active Reconnaissance

Gathering information through direct interaction with a system in an authorized testing environment.

Security Tool Overview

- Nmap – Network discovery and security auditing
- Wireshark – Network packet analysis
- Burp Suite – Web application testing
- OWASP ZAP – Web application security testing
